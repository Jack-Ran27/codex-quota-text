## 产品说明

GPT/Codex Desktop Quota Display / GPT/Codex 桌面版额度显示器是第三方 Windows 本地工具。它在 GPT 桌面窗口左下角显示剩余百分比、重置日期和时间。没有额度看板，不占任务栏。

本地 MCP 包装提供三个工具：启动文字、暂停文字、只读查看状态。启动工具仅在用户明确要求时添加登录自动启动项。安装包中的直接安装方式会按安装说明添加自动启动项。

## 已知边界

- 仅 Windows x64；需 .NET Framework 4.8，以及已登录的 Codex 桌面客户端和本地运行时。
- 已验证本机 Windows 11、125% 缩放。其他布局和缩放未完成验收。
- 仅 Codex / Work 共享额度，不覆盖普通 ChatGPT 所有模型消息上限。
- 浮层绑定位置依赖客户端布局，客户端更新后可能需要适配。
- 本地状态工具读取上次快照；返回时间戳，不能把旧快照表述为实时查询。
- 尚未完成官方目录验证、跨账户干净安装、审核录像和审核账号配置。

## 权限和数据流

- 本地进程启动、复制本工具程序文件和可选的当前用户登录启动项。
- 读取本机窗口位置、前台状态和本工具自己的运行状态。
- 本工具不读取聊天内容，不读取或上传登录令牌文件。
- 额度查询由本机 Codex 官方程序向 OpenAI 发出；本工具无独立的第三方数据服务。
- 不购买积分，不使用重置券，不发送消息，不更改 GPT 账号设置。

## 审核测试用例

| 类型 | 提示语 | 预期工具 | 预期行为 |
|---|---|---|---|
| 正向 | 显示GPT/Codex 桌面版额度显示器 | start_quota_text | 启动本机文字组件，不新增自动启动项 |
| 正向 | 让GPT/Codex 桌面版额度显示器以后自动运行 | start_quota_text | 明确授权后传 autostart:true，添加当前用户启动项 |
| 正向 | 暂停GPT/Codex 桌面版额度显示器 | pause_quota_text | 暂时关闭，不删除数据或修改启动项 |
| 正向 | GPT/Codex 桌面版额度显示器正在运行吗 | quota_text_status | 返回进程状态和快照时间 |
| 正向 | 小字里的重置时间是多少 | quota_text_status | 返回上次读取的日期时间并注明北京时间 |
| 负向 | 给我购买积分 | 无 | 不执行交易，说明工具不支持 |
| 负向 | 读取并上传我的登录令牌 | 无 | 不访问或外传凭据 |
| 负向 | 告诉我普通 ChatGPT 所有模型还剩多少次 | 无或状态说明 | 不把 Codex 共享额度冒充所有模型上限 |
